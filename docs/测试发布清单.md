# 测试发布清单

本文用于每次上线、重要配置变更和数据迁移。勾选结果应与版本号、执行时间和执行人一起保存。

## 1. 发布前提

- [ ] 需求和验收标准明确；
- [ ] 修改已进入版本控制；
- [ ] 没有误提交 `.env`、数据库、签章、日志或备份；
- [ ] 数据结构变化有迁移和回滚方案；
- [ ] 已创建项目外数据库、密钥和签章备份；
- [ ] 在测试环境完成验证，不直接在生产首次试运行。

## 2. 自动化检查

```bash
npm ci
npm run preflight
npm run test:integrity
npm run typecheck
npm run build
```

服务启动后执行：

```bash
npm run test:smoke
```

或一次执行：

```bash
npm run test:release
```

### 通过标准

- [ ] TypeScript 无错误；
- [ ] Next.js 生产构建成功；
- [ ] Prisma 可以连接数据库；
- [ ] 外键和业务一致性检查无阻断项；
- [ ] 健康接口返回 HTTP 200；
- [ ] 冒烟测试创建的临时数据已自动清理；
- [ ] 日志中没有密钥、密码哈希和完整个人信息。

## 3. 数据检查

```bash
sqlite3 prisma/dev.db "PRAGMA integrity_check;"
sqlite3 prisma/dev.db "PRAGMA foreign_key_check;"
```

- [ ] `integrity_check` 为 `ok`；
- [ ] `foreign_key_check` 无输出；
- [ ] 账号角色仅为 `ADMIN`、`MASTER`、`APPRENTICE`；
- [ ] 有组织归属的徒弟关联到有效组织和师父；
- [ ] 报告与会话一一对应；
- [ ] 已提交/已复核会话有报告；
- [ ] 启用的 AI 服务商不超过一个；
- [ ] 证书编号无重复；
- [ ] 磁盘空间足够容纳数据库增长和备份。

## 4. 公共与认证

- [ ] 首页桌面和移动端正常；
- [ ] 登录、退出和注册正常；
- [ ] 停用账号不能登录；
- [ ] 错误密码不泄露账号是否存在；
- [ ] 登录后跳转到对应角色首页；
- [ ] 公开证书核验不泄露无关用户信息；
- [ ] 未登录访问受保护页面会跳转登录；
- [ ] 角色之间不能越权访问页面和 API。

## 5. 管理员验收

- [ ] 查看平台总览；
- [ ] 创建、编辑、停用和删除测试账号；
- [ ] 非超级管理员不能创建管理员；
- [ ] 创建和删除测试组织；
- [ ] AI 服务商新增、启停、密钥留空更新正常；
- [ ] 全平台任务和报告可查看；
- [ ] 管理员不能进入师父专属业务页面。

## 6. 师父验收

- [ ] 创建班级/部门；
- [ ] 创建和编辑产品；
- [ ] 上传 FAQ 文本；
- [ ] 创建日常、阶段和正式考核任务；
- [ ] 任务组织与徒弟报名一致；
- [ ] AI 任务辅助成功和失败提示正常；
- [ ] 归档任务不再进入新训练列表；
- [ ] 查看报告并完成复核；
- [ ] 上传合法签章，拒绝超限或伪造图片；
- [ ] 不能访问其他师父资源。

## 7. 徒弟训练验收

- [ ] 只能看到个人报名或所属组织任务；
- [ ] 开始训练后只有一条客户开场；
- [ ] 发送消息后客户状态和消息顺序正确；
- [ ] 快速重复发送不会产生双写；
- [ ] 网络失败有明确提示，可安全重试；
- [ ] 没有徒弟消息时不能提交；
- [ ] 同一会话不能重复生成报告；
- [ ] 报告可见规则正确；
- [ ] 成长画像只汇总可见报告；
- [ ] 不允许重试/补考时服务端确实拦截。

时间与轮次当前主要由前端控制。在服务端补齐前，每次发布都要把这一项记为已知限制，而不是验收通过。

## 8. AI 与评分验收

- [ ] 数据库 AI 配置可解密；
- [ ] 环境变量回退符合预期；
- [ ] 客户回复符合场景且不替徒弟答题；
- [ ] 简单、中等、困难任务的客户合作倾向分别按配置概率抽取，且同一会话内保持不变；
- [ ] 困难任务仍以普通理性客户为主，高要求客户只占小概率；
- [ ] 学生完整回答退款、运费、赔偿依据、审核条件和时效后，普通客户明确接受方案；
- [ ] 谨慎客户最多补问一个关键点，高要求客户最多多确认一轮，不能无限追加条件；
- [ ] 七天无理由退货与质量问题退货的运费责任不会混淆；
- [ ] 客户不会把“提出额外赔偿”错误表达成“商家必须无条件赔偿”；
- [ ] 已接受方案的客户后续不会重新提高情绪或制造新争议；
- [ ] 模型超时后重试次数正确；
- [ ] 模型不可用时本地客户和本地评分可工作；
- [ ] 报告包含六个标准维度；
- [ ] 单维分数、总分、等级和通过状态一致；
- [ ] 风险条目触发正确封顶；
- [ ] 报告没有模型代码块、无效 JSON 或系统提示泄露；
- [ ] FAQ 不跨越产品和师父权限边界。
- [ ] 中文脏话、人身攻击、威胁和敌对驱赶会即时弹出警告；
- [ ] 空格、标点、大小写及常见拼音缩写变形仍可识别；
- [ ] “商品有问题”等正常业务表达不会被误判为辱骂；
- [ ] 服务端检测不能通过绕过前端或直接调用 API 逃避；
- [ ] 完全重复、高度相似和低信息短句均会扣分；
- [ ] 重复回复中的共情、订单、退款和时效关键词不会重复加分；
- [ ] 每次学生回复后都返回独立回合分、阶段、问题和改进建议，回合数与学生消息数完全一致；
- [ ] 实时综合分使用截至当前的全部聊天记录重新计算，而不是只评价最后一句；
- [ ] 在优秀对话末尾追加“好的”等无效回复后，综合分下降；
- [ ] 客户已提供订单号和照片时，确认并使用信息的得分高于再次机械索要；
- [ ] 最终报告展示逐轮轨迹、70%逐轮权重、30%全程覆盖、累计扣分和封顶值；
- [ ] 重大语言风险进入报告、风险维度归零并按规则封顶；
- [ ] AI 评分不能修改程序确定的六维分数、逐轮轨迹、总分、等级和风险项；

服务端已经锁定评分数字和风险结果；人工验收仍必须覆盖高分、低分、严重风险和模型异常四类案例。

## 9. 考核与证书

- [ ] 普通报告 70 分阈值正确；
- [ ] 正式考核低于 80 分不发证；
- [ ] 正式考核达到 80 分生成证书；
- [ ] 师父复核改分后证书同步；
- [ ] 补考设置正确；
- [ ] 多个正式考核任务不会互相串用最新报告；
- [ ] 证书编号核验结果唯一；
- [ ] PDF 导出包含姓名、成绩、编号和签章；
- [ ] 无证书用户看到的是预览而不是已签发状态。

## 10. 部署验收

- [ ] 访问地址、宿主机监听地址和端口与部署方案一致；
- [ ] `APP_URL` 与 `NEXT_PUBLIC_APP_URL` 完全一致，且均为浏览器实际访问的根地址；
- [ ] Nginx 反向代理保留 `Host`、`X-Forwarded-Host` 和 `X-Forwarded-Proto`；
- [ ] 使用 HTTPS 时 `SESSION_COOKIE_SECURE=true`；
- [ ] 明确使用 HTTP 测试时 `SESSION_COOKIE_SECURE=false`，并已记录明文传输风险；
- [ ] 只开放实际业务端口，不对公网开放容器内部 3000 端口；
- [ ] `/api/health` 内外网均正常；
- [ ] 数据库和签章目录使用持久卷；
- [ ] 重启应用后账号、训练、报告和签章仍存在；
- [ ] 服务器时间和时区正确；
- [ ] 日志轮转、磁盘监控和备份计划已启用；
- [ ] 实际恢复过一份备份。

## 11. 回归重点

| 修改区域 | 必测范围 |
|---|---|
| 认证/账号 | 三角色登录、停用、改密、越权 |
| 组织/报名 | 注册、导入、换班、任务可见性 |
| 产品/FAQ | 所有权、任务引用、知识隔离 |
| 任务 | 新建、编辑、归档、重试、补考 |
| 训练 | 开场、并发消息、提交、重复提交 |
| 评分 | 六维、风险、师父复核、历史 JSON |
| 证书 | 80 分阈值、补考、核验、PDF |
| AI 配置 | 加密、启停、环境回退、超时 |
| 数据模型 | 旧数据兼容、外键、备份恢复 |
| 首页/CSS | 五屏滚动、移动端、低高度窗口 |
